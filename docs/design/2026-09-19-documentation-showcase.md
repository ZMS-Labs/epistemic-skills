# Documentation presentation

This editorial pass makes the released v7 methods easier to understand and
maintain. It changes explanations and presentation, not skill contracts or
release evidence. The README is the short entry; the current handbook carries
examples, boundaries, rationale, and help. Historical snapshots remain separate.

## Selected direction

A technical field guide, designed for reading inside GitHub. Deep ink anchors
the cover, light paper separates the question map, and a restrained orange
marks the observed path. Archivo lettering is outlined into self-contained SVG
so visitors see the same composition without installed fonts or external font
services. The native GitHub layout retains familiar navigation and theme support.

The cover's branching mark illustrates alternatives and an observed next step.
It is not a flowchart that prescribes a fixed skill sequence. The question map
organizes all methods for discovery; canonical applicability remains authoritative.

## Reading order

Purpose and a plain-language definition come first, followed by routine-work
proportionality, an illustrative task, installation, method selection, design
tradeoffs, evidence, and contribution. Detailed host commands move to the
installation guide. Completed publication evidence is linked separately from
the earlier preparation packet. Illustrative examples never become trial results.

## Visual delivery

The cover and question map each have wide and narrow compositions. Native text
repeats their useful meaning; alt text and SVG descriptions support nonvisual
reading. The original vectors, font license, and reproducible generator live
under [docs/assets](../assets/README.md). No JavaScript runs in the graphics.

A standalone marketing website was not part of this pass. GitHub remains the
reading and maintenance surface, so presentation adds no site build dependency.
The wiki publisher pins editorial images and source links to the documentation
commit while leaving behavior links pinned to the v7.0.0 release.
