# Start here

Use `epistemic` for suite usage guidance when it is not already loaded. It teaches
discovery, loading, application, visible use and continuation; the task-owning
agent still performs the task. The historical alias `using-epistemic-skills` has native invocation
that depends on actual host support. Use `epistemic` when
alias support is unavailable. Every substantive method is directly accessible.

Read actual current descriptions, select the applicable method, load its current
instructions and apply them. Briefly acknowledge each skill actually used,
individually or together. Reading or announcing a skill alone is not application.
Reuse sufficient evidence and preserve the user's existing decisions and scope.

Metacognate retains substantive reasoning about assumptions, confidence, evidence,
success criteria and approach. It is not a compulsory dispatcher. Perspective
supports focused or adaptive lens use; Gauntlet supplies plural scrutiny and
reasoned adjudication of a common subject. Reviewer count alone does not decide
which method is appropriate. Helix remains retired.

Routine work needs its relevant check, not a process-only artifact or an inventory
of absent triggers. Continue the authorized task after a bounded method returns.
