# Ordinary examples

| Request | Useful behavior | Stop and return |
|---|---|---|
| Fix a reproducible bug | Triage uses applicable available Superpowers systematic-debugging, or its adequate standalone method; report the actual provider | Repair within authorization and verify the original failure |
| Check one citation | Resolve uses bounded citation verification, expanding only when the question needs it | Report verification depth and uncertainty |
| Review a reversibility concern | Perspective uses a relevant lens and disconfirming evidence | Return an insight or adjustment; no compulsory panel |
| Challenge a consequential design | Gauntlet examines a common subject through distinct questions and adjudicates findings | Preserve dissent; reopen only findings affected by revision |
| Resume interrupted work | Decision-ledger reuses adequate records and re-anchors current state; mission custody applies only when warranted | Continue remaining authorized work |
| Author a goal | Write-goal binds outcome, proof, scope and stop rules; inspect actual native capability if activation was requested | Preserve draft-only intent and user-controlled budgets |
| Verify a UI outcome | Evidence-locked UAT observes expected and disconfirming results and records actual actor/verifier separation | Failed persistence cannot pass because a success message appeared |

A local copy edit can finish with a preview and a relevant check. No method requires
new questions merely to fill a quota. Factual unknowns should be investigated;
user-owned consequential decisions may need clarification.
