# Release process and versioning

The [current release policy](https://github.com/ZMS-Labs/epistemic-skills/blob/v7.0.0/RELEASING.md) governs candidate review,
integrity checks, publication authorization and immutable tag/Release identity.
The [v7 release notes](https://github.com/ZMS-Labs/epistemic-skills/blob/v7.0.0/docs/release/RELEASE-7.0.0.md) must be read together
with their [evidence packet](https://github.com/ZMS-Labs/epistemic-skills/blob/v7.0.0/docs/release/v7-evidence.md).

Source preparation is distinct from local commit, pushed source, installed copy,
loaded context, exercised behavior and publication. The release page and its
recorded judgment establish publication status; this snapshot alone does not.
Historical v6 review results, owner exception, assurance records and tests retain
their original subjects and meaning.

Versioned installation links identify v7.0.0. Publish this handbook only after
that tag and GitHub Release exist and their source identity is verified. Do not
rewrite old snapshots or move published tags to make documentation consistent.
