# Release process and versioning

The [current release policy](../../../../RELEASING.md) governs candidate review,
integrity checks, publication authorization and immutable tag/Release identity.
The [v7 candidate notes](../../../release/RELEASE-7.0.0.md) must be read together
with their [evidence packet](../../../release/v7-evidence.md).

Candidate preparation is distinct from local commit, pushed source, installed
copy, loaded context, exercised behavior and publication. No v7 release or final
release judgment is claimed here. Historical v6 review results, owner exception,
assurance records and tests retain their original subjects and meaning.

Versioned installation links remain pinned to the existing v6.0.0 release until a
real successor tag is published and its identity verified. Do not rewrite old
snapshots or move published tags to make current documentation appear consistent.
