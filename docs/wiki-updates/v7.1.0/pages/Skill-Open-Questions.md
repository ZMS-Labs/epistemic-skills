# Open Questions

**Resolve the decisions that genuinely belong to the user.**

Open Questions runs a visible, bounded interview. An explicit request can ask to exhaust the material question set. An automatically triggered interview stays focused on a consequential fork that cannot safely be inferred.

**Use it when:** You ask to be interviewed, or an irreversible or high-impact user-owned choice blocks work and you are available to answer.

**Use something simpler when:** The agent can research the fact itself, a routine reversible default is sufficient, or a design or goal-authoring method already owns the conversation.

### Illustrative request

> Walk me through the remaining rollout decisions one at a time. Reuse what we already agreed and start with decisions that other answers depend on.

**What a useful result looks like:** A visible docket of resolved, deferred, struck, and held decisions. The interview ends when the scoped questions are exhausted and the closing probe finds nothing, or when the user releases it.

**Boundary:** Releasing the interview does not grant missing authority for a consequential act. Independent authorized work continues while only the affected action remains held.
