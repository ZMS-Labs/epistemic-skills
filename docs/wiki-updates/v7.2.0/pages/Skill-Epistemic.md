# Epistemic

**Use the suite without turning every task into a ceremony.**

Begin with the usage guide, then let the task determine which methods matter. The guide explains discovery, actual instruction loading, visible acknowledgment, and continuing the original authorized work. It does not choose every method or create a task ledger.

**Use it when:** You are beginning with the suite, have lost its usage guidance after context changes, or explicitly want to understand how to use it.

**Use something simpler when:** The guidance is already loaded and nothing relevant changed. Any substantive method can also be invoked directly.

### Illustrative request

> Use Epistemic Skills for this task. Load the methods that apply, briefly tell me what they contributed, and carry the authorized work through verification.

**What a useful result looks like:** The agent loads applicable instructions, reports substantive contributions briefly, and continues. A useful acknowledgment says what a method examined or changed; a startup banner alone proves neither application nor benefit.

**Boundary:** Metacognate examines reasoning; this guide explains how to use the suite. Native invocation and automatic loading depend on the host.
