# Choosing a Skill

Choose from an observed trigger, not from the size of the task or a desire to be thorough. The default is ordinary work; additional process is justified only when it can expose an error that could change the action or completion claim.

## Start with this decision

| What you can observe | Next step |
|---|---|
| All four routine conditions hold | Use the bounded ordinary workflow; no special record. |
| A remembered summary or handoff controls the next action | `decision-ledger` resume mode (continuity-verify) re-anchors state before resumed work. |
| A request conflicts with territory, hides coupling, is materially unclear, or risks multiplying a wrong premise | `recon` (brief mode, the blindspot pass) performs read-only recon. |
| A large foggy effort's path holds unresolved decisions, or a backlog encodes unmade decisions | `recon` (initiative mode, wayfinding) decomposes by decisions and mints fog-free tickets. |
| An external project overlaps your own work and the question is adopt / replace / ignore | `recon` (candidate mode, harvest-before-adopt) harvests transferable ideas first. |
| A material design/property claim needs a derivation | `resolve` (derivation instrument) derives it from an explicit model and preconditions. |
| A claim depends on research or a scholarly tool call | `resolve` (literature instrument) checks reception and durable holdings. |
| A live question is cheaper to answer with a disposable build than more argument | `resolve` (probe instrument) builds to answer one pre-registered question, then disposes. |
| The user explicitly asks to author or start a persistent goal | `write-goal` establishes the completion contract. |
| Work crosses to an external model, agent, or process | `outsource` prepares the committed, target-readable handoff. |
| A one-way-door or high-blast-radius decision is imminent | `gauntlet` evaluates the frozen subject. |
| A material UI-facing completion claim needs independent proof | `evidence-locked-uat` supplies the evidence and blinded verdict. |
| A consequential decision, assumption, or recurrent correction lacks a durable record | `decision-ledger` persists the future-facing context. |
| The operator asks to be interviewed until no open questions remain, or an un-best-guessable irreversible fork arrives with the operator present | `open-questions` walks the question ledger to empty or parked. |
| An explicit audit request, a detected cross-layer instruction conflict, or a model-generation upgrade | `context-audit` audits the assembled instruction context. |

If more than one positive trigger exists, `using-epistemic-skills` sequences them and defines what each output must hand to the next. If none exists, none fire.

## Where Helix fits

The router chooses within the epistemic layer. When a workflow-skill layer also runs, [Helix: Central Passage](Helix-Central-Passage) pairs a positively triggered discipline with its workflow stage. Helix is not a replacement router and does not turn absent pairings into work.

## Keep the negative path real

The routine path is not a lesser result. It is the correct result when the four conditions hold after the two-read micro-recon, and it stays silent. [Routine Work and Proportionality](Routine-Work-and-Proportionality) defines the gate; [Skill Catalog](Skill-Catalog) provides the individual reference guides.
