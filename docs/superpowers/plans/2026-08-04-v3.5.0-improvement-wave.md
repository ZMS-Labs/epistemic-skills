## Why this ordering

Two recon passes over the suite's own honest-limits declarations (2026-08-04,
session-preserved; key findings reproduced here so the trail survives):

1. **Evidence debt dominates, inversely correlated with centrality.** Only
   continuity-verify and the router's proportionality campaign have committed
   passing behavioral evidence. Eight batteries ship `results/BLOCKED.md`;
   decision-ledger and evidence-locked-uat have structural fixtures with no
   results record; blindspot-pass, evidence-research, write-goal, and
   outsource — the oldest, most-fired, arc-core disciplines — have **no eval
   surface of any kind**. The six newest skills have full deterministic
   batteries never fired at a live model.
2. **Independence is structurally unachieved.** All gauntlet seats same model
   family; Step-7b (issue #40) never run; the amended arbitrator-certification
   battery is `NOT_RUN` and the skill disowns the old 10/10.
3. **Inventory drift recurs.** The ECS `producer.skill` enum and
   `skill-event-map.json` are frozen at 11 skills — the six newest disciplines
   cannot emit a valid epistemic event. (The audit's `SKILL_PATHS` drift got
   its tripwire in PR #76.)
4. **The runtime-enforcement category limit (#42)** needs harness machinery
   (a tool-call gate), not more markdown.
5. **Release surfaces drift** without a mechanical check that evidence claims
   match the tree (this wave's truth-sync commit fixes the current instances;
   a release-claims checker is a candidate for the substrate track).
