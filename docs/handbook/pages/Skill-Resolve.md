# Resolve

**Choose the evidence method that can actually settle the question.**

Resolve selects among a derivation, literature investigation, or disposable probe. The choice follows the question, existing evidence, assurance need, and cost. These are instruments with different strengths, not a fixed ladder from light to heavy.

**Use it when:** A live correctness, research, or empirical question cannot be settled by an ordinary bounded read or check.

**Use something simpler when:** The matter is pure preference, the direct check already answers it, or the decision is already made and the research would only decorate it.

### Illustrative request

> Can this queue design lose an acknowledged item during restart? Use the cheapest sufficient method to answer that specific question.

**What a useful result looks like:** A supported answer, counterexample, or named limit, with the relevant derivation, claim-evidence matrix, or probe record. A probe declares its question and disposal boundary before execution.

**Boundary:** A toy probe does not prove production behavior. A citation does not by itself verify a scientific claim. The resulting evidence informs the decision owner; it does not issue an implementation approval.

[Recon](Skill-Recon.md) maps territory; [Gauntlet](Skill-Gauntlet.md) can adjudicate a consequential decision using the resulting evidence.
